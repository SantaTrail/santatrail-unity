# SantaTrail Unity

Unity project for SantaTrail gameplay, map interaction, drone simulation hooks, and telemetry/video bridge utilities.

## Project Structure

- `Assets/` Unity scenes, scripts, prefabs, materials, and resources
- `Packages/` Unity package dependencies
- `ProjectSettings/` Unity project configuration
- `Assets/Scripts/` gameplay + integration scripts

## Prerequisites

- Unity Editor (open this folder as a Unity project)
- Python 3.9+
- `ffmpeg` installed and available on `PATH` (required for video streaming scripts)

## Python Setup

From this folder:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Notes

- `Library/` and `Logs/` are generated by Unity and can be large.
- Keep runtime/asset-heavy folders out of regular source-control snapshots when appropriate.
